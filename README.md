# mind penalykick v3.6.2

브라우저에서 실행하는 5번 슈팅·3골 승리 페널티킥 심리전 게임. 로그인·서버·설치 없이 실행할 수 있도록 HTML/CSS/JavaScript로 제작했습니다.

## 실행

1. `mind-penalty-game` 폴더에서 `index.html`을 Safari, Chrome 등의 브라우저로 엽니다.
2. **START MATCH**를 누릅니다. 우측에 전술 수첩이 표시됩니다.
3. **1 / 2 / 3** 또는 **← / →**로 슈팅 방향을 고릅니다.
4. **SPACE**를 눌러 타이밍을 시작하고, **SPACE**를 다시 눌러 킥합니다. 중앙의 PERFECT / GOOD 범위를 노리세요.
5. 슈팅 결과를 확인하고 **ENTER** 또는 NEXT KICK을 누릅니다. 다섯 번의 슈팅이 끝나면 MATCH REPORT가 나타납니다.

조작: `1 2 3`, `← →`, `SPACE`, `ENTER`, `P`(일시정지/재개), `ESC`(메뉴 닫기/일시정지). 마우스/터치 버튼도 제공합니다.

## 경기 판정과 골키퍼 AI

- 5번의 슈팅 중 3골 이상이면 승리. 반드시 5번을 모두 진행합니다.
- 타이밍이 **MISS**라면 골대 밖으로 나갑니다. **GOOD** / **PERFECT**여도 골키퍼가 같은 방향으로 다이빙하면 선방입니다.
- 세 골키퍼는 첫 세 라운드에 각 1회 등장합니다. 같은 골키퍼 연속 등장은 발생하지 않습니다. 4~5라운드는 앞선 상대와 겹치지 않는 무작위 선택입니다.
- **T.쿠르투아**는 직전 슈팅 방향으로 다이빙합니다.
- **알리송**은 직전 방향의 오른쪽 한 칸으로 다이빙합니다(왼쪽→중앙→오른쪽→왼쪽 순환).
- **M.노이어**는 현재까지 가장 많이 고른 방향을 방어합니다. 최다 동률에 직전 방향이 있으면 직전을 우선합니다.
- 첫 슈팅에서는 골키퍼별 고유한 첫 방어 방향을 사용합니다.

위 정확한 규칙은 플레이 중에는 가리고, 경기 종료 후 MATCH REPORT에서 공개합니다. 전술 수첩은 오른쪽에 표시되며 이전 슈팅 내역은 항상 볼 수 있습니다.

## 단서 단계

| 난이도 | 1단계 대사/기본 | 2단계 행동 단서 | 3단계 결정적 단서 | 실제 AI 규칙 |
|---|---|---|---|---|
| EASY | 1R | 2R | 3R | 경기 종료 후 |
| NORMAL (기본) | 1R | 3R | 4R | 경기 종료 후 |
| HARD | 1R | 4R | 5R | 경기 종료 후 |

난이도는 정보 공개 시점만 변경하며 실제 골키퍼 AI의 판정 방식은 변경하지 않습니다. 진행 중 난이도는 고정되며 새 경기부터 변경이 적용됩니다.

## 플레이 집중 모드

START MATCH 이후 전용 화면으로 전환하며 경기장/방향 선택/타이밍 게이지/전술 수첩이 함께 나타납니다. 데스크톱 1366×768 및 1366×680에서 버튼까지 스크롤 없이 표시되도록 설계했습니다. 모바일 화면에서는 가독성을 위해 전술 수첩이 경기장 아래로 이어져 세로 스크롤이 필요할 수 있습니다.

키커 뒤의 3인칭 시점, 슈팅 순간에만 약한 확대, 골키퍼의 좌/중앙/우 다이빙, 별도의 선수 리액션, 앞줄 캐릭터·뒷줄 실루엣 관중, GOAL/SAVE/OUT 반응이 적용됩니다. '움직임 줄이기' 설정을 켜면 애니메이션을 최소화합니다.

## 이어하기와 기록

- 경기 중 P → MAIN MENU 선택: 라운드, 득점, 골키퍼 순서, 슈팅 기록, 타이밍 상태, 경과 시간을 유지합니다.
- 메인 화면의 CONTINUE MATCH를 누르면 일시정지 상태로 돌아가며, RESUME을 누르면 재개합니다.
- 중요한 상태가 바뀔 때 브라우저 localStorage에 자동 저장합니다. 새로고침/브라우저 재접속도 이어하기 대상입니다.
- 현재 브라우저와 같은 사이트 주소에서만 동작합니다. 브라우저 정책으로 localStorage가 제한될 때는 저장되지 않을 수 있습니다.
- NEW MATCH는 현재 경기 포기 확인을 요청합니다. 이미 완료한 경기의 기록은 유지합니다.
- 5라운드 종료 시 누적 기록에 **한 번만** 저장하고 이어하기 대상에서 제외합니다.
- RECORDS에서 누적 경기, 승리, 최고 점수를 확인하고 CSV 내보내기를 사용할 수 있습니다.

## 사운드 (v3.6.2)

- 실제 경기장 녹음·외부 음원 접속을 없앴습니다. **경쾌한 플래시/아케이드 게임 느낌**의 자체 합성 WAV 4종을 사용합니다.
- 준비 중에는 작고 가벼운 `arcade-chatter.wav`를 반복하고, 타이밍 조작을 시작하면 소리가 더 작아집니다.
- 득점은 밝고 올라가는 `arcade-goal.wav`, 선방은 내려가는 `arcade-save.wav`, 실축은 익살스러운 `arcade-out.wav`로 구분합니다.
- 공차기·버튼 클릭 효과는 Web Audio API에서 재생됩니다. WAV/효과음은 사용자 조작 후 시작됩니다.
- 전체 음소거, 전체 음량, 관중 소리, 효과음 조절을 유지하며 모든 사운드가 오프라인에서 동작하도록 구성했습니다.
- WAV가 재생되지 않는 특수 환경에서는 결과 표시와 기본 Web Audio 효과음은 계속 이용할 수 있습니다. 실제 출력 음색은 Safari에서 직접 들어 확인하세요.

## 캐릭터와 실점 반응 (v3.6.2)

- 키커와 골키퍼의 SVG를 피부·유니폼·바지·양말·신발별 **명암과 윤곽을 가진 다층 일러스트**로 변경했습니다. 3D 모델이나 사실적인 3D 렌더링은 아닙니다.
- 골키퍼는 좌·중앙·우 다이빙 후, 실점 시 **그 방향의 착지 위치에서 몸을 바로 세워 무릎을 꿇고 양손으로 머리를 감싸는 별도 포즈**로 바뀝니다.
- 선방·실축 시의 기존 동작과 다이빙 AI 판단 규칙은 변경하지 않았습니다.
- 결과를 본 상태에서 홈으로 이동하거나 브라우저를 다시 열어도 같은 실점 포즈가 표시됩니다.

## 데이터 보호

외부 계정·서버 업로드·개인정보 입력 기능이 없습니다. 경기 기록은 브라우저 로컬에만 저장됩니다. 브라우저 로컬 저장소를 지우면 현재 경기와 완료 기록을 복구할 수 없습니다.

## 파일 구성

- `index.html` : 메인 메뉴/경기장 SVG/전술 수첩/결과 화면/팝업

- `assets/arcade-*.wav` : 오프라인 아케이드 웅성거림·득점·선방·실축 효과음
- `AUDIO_CREDITS.md` : 라이선스·출처
- `V3.6_CHANGELOG.md`, `V3.6.1_CHANGELOG.md`, `V3.6.2_CHANGELOG.md` : 버전별 변경 사항
- `TEST_RESULTS_V3.6.md`, `TEST_RESULTS_V3.6.1.md`, `TEST_RESULTS_V3.6.2.md` : 버전별 자동화 검사 및 제한 사항
