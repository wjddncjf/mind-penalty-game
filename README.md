# MIND PENALTY v3 — 골키퍼를 읽어라

SKT ALEPH 과제 2 「내가 설계한 미니게임」의 **심리전 + 타이밍 액션 확장판**입니다. 바뀐 사항: 더 큰 경기장, **좌우 다이빙 모션**, 골키퍼 3인, **슈팅 라운드별 무작위 골키퍼 등장**, 정체가 드러나지 않는 이름, 골키퍼별 움직임 이력.

## 게임 시작 및 조작

1. ZIP 압축을 푼 뒤 이 폴더의 `index.html`을 브라우저에서 열거나 VS Code Live Server로 엽니다. 별도 설치·계정·외부 라이브러리가 없습니다.
2. **게임 시작**을 누르면 골키퍼 **녹턴·오로라·베일**이 섞인 출전 순서가 생성됩니다. 플레이어가 골키퍼를 직접 선택하지는 않습니다. 첫 3라운드에서 세 명이 무작위 순서로 1명씩 나오고, 4~5라운드에서도 무작위로 뽑되 연속 중복 출전은 방지합니다.
3. `←`, `→` 키로 조준을 이동하거나 `1`, `2`, `3`으로 왼쪽·중앙·오른쪽을 바로 선택합니다. `SPACE` 혹은 **타이밍 시작**을 누르면 게이지가 왕복하며, 다시 `SPACE` 또는 **지금 슈팅!**을 누르면 확정됩니다.
4. 타이밍이 GOOD 또는 PERFECT이고 골키퍼가 다른 방향으로 뛰면 골, 같은 방향이면 선방입니다. MISS는 실축으로 처리합니다. PERFECT도 골키퍼가 막을 수 있습니다. 결과와 오른쪽의 **전술 수첩·슈팅 기록**을 관찰한 후 **다음 킥**(`ENTER`)으로 진행합니다.
5. 5번의 슈팅에서 **3골 이상 승리**, 그 외는 패배입니다. **다시 시작**하면 현재 판 값만 초기화하고 상대 출전 순서를 다시 섞습니다.
6. `P` 또는 버튼으로 일시정지/재개합니다. 창을 떠나면 자동 일시정지됩니다. **움직임 줄이기**를 켜면 슈팅/다이빙/득점 애니메이션이 즉시 멈춥니다.

## 골키퍼의 숨겨진 패턴 (개발·테스트용 스포일러)

처음 플레이하는 사람에게는 이 섹션을 미리 보여주지 마세요. 이름은 행동 규칙을 직접 암시하지 않습니다.

| 이름 | 행동 규칙 |
|---|---|
| 녹턴 | **직전 슈팅 방향**으로 다이빙 (첫 등장 킥이 1차라면 중앙) |
| 오로라 | **직전 슈팅 방향보다 오른쪽으로 한 칸** 이동 (오른쪽 다음은 왼쪽; 첫 킥이라면 오른쪽) |
| 베일 | **이번 판에서 가장 많이 찬 방향**을 경계 (동률이면 직전 슛 우선, 첫 킥이라면 왼쪽) |

서로 다른 이름과 행동 규칙을 연결해 관찰하도록 했습니다. 단서 공개 시점은 2·3·4번째 슛 가운데 하나를 설정할 수 있습니다. 결과 기록에는 골키퍼 출전 순서를 함께 남깁니다.

## 과제 카드 3: 실제로 20회 검사하기

1. **단서 공개 시점 3번째 슛**을 유지하고 10판 연속 플레이합니다.
2. 나머지 설정과 규칙은 그대로 두고 **단서 공개 시점만 2번째 슛**으로 바꿔 10판 플레이합니다.
3. **기록 CSV 저장**으로 결과를 내보내 득점·시간·실축 또는 선방 원인·골키퍼 출전 순서를 확인합니다.
4. 두 그룹의 점수 범위·중앙값 또는 반복 실패 원인을 비교하고 **직접 최종 난이도를 선택**합니다. 골키퍼 출전 순서는 매 판 무작위이므로 그 변동도 결과 해석에서 고려해야 합니다.

20회 플레이 기록은 **아직 실제로 수행하지 않았습니다**. 예시나 자동화로 만든 기록을 본인 실측 결과로 제출하면 안 됩니다.

## 저장·초기화 및 v1 기록 승계

- `localStorage` 키: `mind-penalty-v2` (v3에서도 기존 v2 기록 보존을 위해 같은 키 사용; 이전 `mind-penalty-v1` 기록을 최초 진입 시 검증 후 읽어와 복구합니다).
- 보존할 값: 경기 완료 횟수·승수·최고 점수·난이도·움직임 줄이기 설정·최근 100경기의 결과와 골키퍼 출전 순서.
- 새 판에서 초기화할 값: 라운드·득점·조준 및 조준 횟수·경과 시간·현재 판 슈팅 기록·골키퍼 순서.
- 저장 데이터가 없거나 손상되어도 기본값으로 재시작. **기록 초기화**는 이전 버전 키를 포함해 저장된 경기 기록과 설정을 삭제합니다. 손상 검사 전 CSV 백업을 권장합니다.
- 모든 기록은 **현재 브라우저 내부에만 저장**됩니다. 서버 전송·로그인·개인정보 수집이 없습니다.

## 공개 배포 및 제출

1. GitHub에서 새 **공개** 저장소(예: `mind-penalty-game`)를 생성합니다.
2. 이 폴더 안의 `index.html`, `styles.css`, `game.js`, `README.md`를 저장소 **최상위 경로**에 업로드합니다.
3. `Settings → Pages → Deploy from a branch → main / (root)` 설정 후 표시되는 게시 주소를 확인합니다.
4. 과제에는 실제 공개 게임 URL 및 **40자리 커밋 해시**가 포함된 GitHub 커밋 URL을 제출합니다. ZIP 자체를 과제에 제출하지 않습니다.
5. 결과물 및 소스가 시크릿 창에서 로그인·비밀번호·OAuth·CAPTCHA 없이 열리는지 **실제 확인**합니다.

`TEST_CHECKLIST.md`와 `TEST_RESULTS.md`를 검사 기록에 활용하세요. 공개 배포, 실제 10분 연속 실행, 20회 실측 비교 등은 아직 미완료입니다.

## v3 슈팅 타이밍 설계 및 테스트

- 게이지는 1.4초 주기로 좌우 왕복합니다. 중앙 ±8%는 PERFECT, 중앙 ±23%는 GOOD, 그 외는 MISS입니다.
- 타이밍은 슛의 정확도에만 관여합니다. GOOD/PERFECT의 득점은 기존 골키퍼 패턴과 선택 방향으로 결정됩니다. MISS는 자동 실축입니다.
- 일시정지/창 전환 시 게이지와 경기 시간이 함께 멈추며 재개 시 이어집니다. 움직임 줄이기를 켜도 판정 방식은 동일합니다.
- 기록의 기존 `saves` 필드는 과거 데이터 호환을 위해 유지되며 실제 의미는 미득점 수(선방 + 실축)입니다. 개별 실패 원인에는 실축과 선방을 구분해 표시합니다.
- 카드 3 난이도 비교에서는 v3 규칙을 고정하고 10+10판을 직접 플레이하세요. v2와 v3 기록을 동일 규칙의 실험 표본으로 섞지 마세요.
